Privacy

Last updated: 15 September 2026

This site collects as little as possible. There is no tracking, no advertising, and no analytics on these pages.

What is collected

Server logs. The web server (Apache) keeps standard access logs: your IP address, the page requested, the time, and your browser's user-agent string. This is normal for any web server. Logs are kept on the server only, are not shared with anyone, and are rotated.

Nothing else. These pages set no cookies, load no third-party trackers, and do not fingerprint visitors.

Interactive tools

MIDIComposer and the converter pages run in your browser; your files and prompts are not uploaded.

Older data

User data from the site's previous quiz, story, and word-game features was deleted in September 2026 when those features were removed. If you had an account on any of them, it and everything attached to it is gone.

Your rights

If you have questions about anything above, or want to know whether any log entry concerns you, email lukasbohez@gmail.com.
