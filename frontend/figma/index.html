What It Does

Extract everything from any Figma file into structured, reusable formats.

📊

Data Extraction

Export JSON/text data — full extract, text only, variables, styles, components, and pages.

🎯

Selected Nodes

Export only the nodes you've selected in Figma as SVG, PNG, JPG, or raw SVG code.

🗂️

Batch Export

Export every node on the current page (or all pages) as SVG/PNG with real-time progress.

🧠

AI-Ready Output

Full extract JSON contains everything — drop it into any LLM for complete design context.

🎬

After Effects / Lottie

Lottie JSON Bundle export with embedded SVGs and position metadata for motion design.

🎨

Design Tokens

Export Formats

Choose exactly what you need — from raw SVGs to complete structured JSON.

FormatUse Case
SVGVector graphics → After Effects, websites, AI tools
PNGRaster images at chosen scale (1x–8x)
JPGCompressed raster for web/email previews
SVG CodeRaw SVG markup as .svg text files
JSONStructured data for scripts, AI pipelines, database imports
TXTPlain text for LLM context, copy-paste workflows

Full Extract Output Structure

{FileName}_full-extract.json ← Complete structured data
{FileName}_text.json ← All text nodes with typography
{FileName}_text.txt ← Plain text dump (AI-friendly)
{FileName}_variables.json ← All design variables
{FileName}_styles.json ← All styles (paint, text, effect, grid)
{FileName}_components.json ← All components
{FileName}_pages.json ← Page structure

// Each node as individual file:
node-name.svg / node-name.png
page-name/node-name.svg (page-prefixed)

How to Install

Get the plugin running in Figma in under a minute.

Option A — Figma Desktop (recommended)

  1. Download the latest .zip from GitHub Releases
  2. In Figma: Plugins → Development → Import plugin from manifest
  3. Select manifest.json
  4. Done — open any Figma file and run "Extract All"

Option B — Build from Source

git clone https://github.com/Lukas-Bohez/figma-extract-all.git
cd figma-extract-all
npm install && npm run build
